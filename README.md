# Ali Ayaan · Hero Times

Kid-friendly multiplication trainer with a superhero theme.

- Difficulty levels (1–5 through 1–15)
- Endless / fixed rounds / timed modes
- Shuffle toggle
- Missed facts repeat more until 5-in-a-row mastery
- Stars, streaks, badges, unlockable heroes, hero map, parent summary
- Progress saved in the browser

Open `index.html` locally, or use the GitHub Pages URL after deploy.
